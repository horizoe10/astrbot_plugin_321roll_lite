# 计划时间与叙事走向指南

除了眼前的检定与交涉，长线冒险往往包含严密的计划部署、日程与时限压力、长线研究项目，以及对宿命运势与大结局的探寻。

---

## 1. 行动计划与分工执行

面对潜入城堡、跨城押运或破解重重机关等复合挑战，团队应预先拟定清晰的分步计划。

### 拟定计划
制定计划标题、整体目标与分解步骤（用竖线 `|` 分隔）：
```text
/团 计划 钟楼潜入行动：夺回怀表｜切断主钟摆绳索｜破译密室密码盘｜从飞天滑索撤离
```
生成计划编号（如 `#4`）。

### 认领步骤
队员主动承揽某项具体工作：
```text
/团 计划 #4 认领 1    # 认领第 1 步
```

### 分步执行
当行动展开时，按步骤进行突破并投掷检定：
```text
/团 执行 #4 1 用特制酸液腐蚀主钟摆的悬挂轴承 [敏捷 标准]
```
步骤逐个突破后，计划将走向圆满成功；若中途败露，可执行 `/团 计划 #4 撤离` 紧急止损。

## 2. 时间、日历与期限

世界引擎内置日历时钟（每日分为：`清晨`、`白天`、`傍晚`、`夜晚` 四个时段）。

### 查看与推进时间
- **查看当前时间**：`/团 时间`（例如显示：“第 2 日 · 傍晚”）。
- **消耗时段展开活动**：
  ```text
  /团 时间 花费 1 在集市中搜集旧书与草药
  ```

### 设立与完结期限
当剧情存在倒计时危机（如暴风雨来临前、公审开庭前）时，设定时间期限：
```text
/团 期限 军械库搜查令生效 第3日 白天
```
在期限到来前达成目标，由队伍完成履约：
```text
/团 期限 #5    # 标记完成期限
```

## 3. 长期项目与队伍休整

### 长期项目（时钟时轮）
诸如破译古籍、打造传奇兵器、训练魔宠等需要累积努力的事项，可立项为长期项目：
```text
/团 项目 破译古代泥板铭文 [6]    # 设立需累积 6 点进度的项目
/团 项目 #6 推进 查阅大图书馆典籍进行对照翻译 [学识 标准]
```

### 队伍安全休整
当体力不支或资源耗尽时，寻找安全据点度过一个时段：
```text
/团 休整
```
- 推进 1 个自然时段。
- 刷新所有标记为“休整后恢复”的技能与物品使用次数。
- 由 AI 描写休整期间的围炉夜话与身心缓和。

## 4. 机运判定与神谕建议

当角色所求之事不取决于实力（属性），而纯粹取决于“命途运势”时，调用机运与神谕。

### 机运抽签（d20）
对吉凶未卜的机运进行问卜：
```text
/团 机运 翻开这本无名遗物能否找到离开迷宫的地图？
```
后台掷出 d20 并划分为三档：
- **厄运 (1–5)**：局势恶化或生变故。
- **平稳 (6–15)**：平淡寻常，不增不减。
- **好运 (16–20)**：天随人愿，获得意料之外的助力。

生成的机运编号可在适当时机正式兑现：
```text
/团 机运 #7 兑现 恰好在书夹层中抖落出一张手绘羊皮图
```

### 神谕是非建议
向冥冥中的叙事神谕提出是非问题（仅作为叙事灵感与概率建议，不捏造既成事实）：
```text
/团 神谕 很可能 这扇铁门背后有巡逻的守卫吗？
/团 神谕 五五开 井底是否还留有未被污染的水源？
/团 神谕 不太可能 那个沉默的铁匠认出了我们身上的徽记吗？
```
神谕给出倾向性回答，为主持人或玩家提供创作指引。

## 5. 角色转变与宿命走向

在波澜壮阔的故事中，经历磨难的角色往往会发生心境蜕变或特质更迭。

### 提出与确认转变
```text
/团 转变 林晓 破晓守望者：从迷茫的求知者转变为坚定的守墓卫士
```
- 为尊重玩家对自身角色的掌控权，转变必须由**角色本人**发送指令予以确认，才会正式生效：
```text
/团 转变 #8 确认
/团 转变 #8 拒绝
```

## 6. 分支与多结局走向

当幕篇推进至高潮，故事不再局限于单一终点，而是由全队共同谱写命运结局。

### 提出结局分支
针对当前世界格局，提出一个可能走向：
```text
/团 结局 提出 永恒封印：以全队神器为代价将虚空裂隙彻底沉入地底
/团 结局 提出 破旧立新：打破古老结界，让灵潮与凡尘全面融合
```

### 投票支持分支
队员们对认可的分支表达支持：
```text
/团 结局 #9 支持
```

### 全员进入结局
当**全体在场队员**均支持同一结局分支后，触发进入结局：
```text
/团 结局 #9 进入
```
叙事模型将根据此分支生成波澜壮阔的高潮终幕故事。

### 书写个人尾声与正式完结
进入结局后，每位玩家为自己的角色写下一段后日谈尾声：
```text
/团 尾声 #9 许多年后，林晓在海崖边建起了一座小灯塔，静静等待着风暴归航。
```
全员尾声齐聚后，由主持人执行结案：
```text
/团 结局 #9 完结
```
故事圆满落幕，全桌记录封存归档。
