# 核心规则与行动指南

321Roll Lite 将传统跑团中的流程判定与即兴叙事拆解为轻量、明确的群聊交互。本指南介绍基础跑团流程、回合机制、d20 检定规则、技能与物品系统，以及私聊与群聊联动玩法。

---

## 1. 跑团基础流程

一局游戏通常分为四个阶段：

1. **开桌选界**：管理员或主持人在群内发送 `/团 开启 [序号]` 选定世界模板。
2. **入座建卡**：玩家发送 `/团 加入` 入座，私聊 bot 发送 `/团 选职业 [序号] [角色名]` 完成建卡。
3. **开演推进**：主持人发送 `/团 开演`，AI 生成序章情境并给出第一轮行动选项。
4. **轮流结算**：玩家轮流在群内选择候选选项或自由行动，由插件裁定检定后，交给 AI 续写故事走向。

---

## 2. 回合与行动机制

游戏采用顺序轮流行动制，在当前玩家的回合内进行抉择。

### 选项行动（推荐）
系统每轮由 AI 即兴生成 A–D 四个方向的行动建议，标有行动意图与潜在风险：
```text
/团 选 A
/团 选 A 小心地用手电筒照向拐角
```
*提示：选项后可附带一句角色口吻的演绎细节，AI 会将其自然融入后续叙事。*

### 自由行动
若候选选项不符合你的策略，可直接描述自主行动：
```text
/团 行动 我爬上货架试图切断吊灯电线 [敏捷 标准]
```
*提示：自由行动句末可声明希望调用的属性与预估难度。*

### 回合状态与跳过
- 查看当前回合谁在行动与候选选项：`/团 回合`（或 `/团 倒计时`）。
- 查看全队行动轮次：`/团 顺序`。
- 回合超时或挂机时主动让渡：`/团 跳过`。

### 超时保护机制
为避免个别玩家离线卡桌，每回合设有倒计时（默认 5 分钟，主持人可调）：
- 倒计时耗尽时，系统将自动判定该玩家选择了当前“风险最低”的选项。
- 自动推进确保故事不会长时间停滞。

## 3. d20 检定规则

凡是涉及风险、不确定性或技能挑战的行动，均由插件在后台掷出 20 面骰（d20），AI 主持人无法随意篡改骰果。

### 检定算式
```text
检定最终值 = d20 投骰结果 + 角色属性加值 + 技能/物品修正值
```

最终值与对抗难度（DC）比较：
- **简单 (8)**：稍作尝试即可达成的常规动作。
- **标准 (12)**：需要专业素养或一定运气的考验。
- **困难 (15)**：高风险、高对抗的关键阻碍。
- **极难 (18)**：极其苛刻、九死一生的绝地挑战。

投出自然 20（Nat 20）视为**大成功**，投出自然 1（Nat 1）视为**大失败**。骰果与计算过程会直接公示在回执中，再交付叙事引擎生成对应情节。

## 4. 技能与物品系统

角色在建卡时获得职业专属技能与初始物品。善用装备与消耗品能显著提升检定胜率或化解危机。

### 检定时追加技能与物品
进行带有检定的行动时，在指令末尾使用 `[用 名称]` 挂载增益：
```text
/团 选 B [用 登山镐]
/团 行动 我用撬棍撬开生锈的铁门 [力量 标准] [用 撬棍]
/团 选 C [用 潜行手札、暗影斗篷]
```
- **属性匹配**：技能或物品所绑定的属性加值必须与本次检定属性一致。
- **消耗前置**：使用的资源消耗会在检定掷骰前核算扣除，本次行动产生的可能恢复不能抵消前置消耗。

### 直接使用物品
无需检定、直接消耗资源或次数触发效果的操作：
```text
/团 使用 急救绷带
```
- 此操作不占玩家轮流行动回合，但需等待正在结算的行动完毕。
- 物品按设定数量扣减，技能扣减使用次数。

### 恢复周期
技能与物品的使用次数具有不同的恢复时机：
- **每幕恢复**：在剧情进入下一幕或主持人执行 `/团 主持 新场景` 时回满。
- **休整后恢复**：队伍执行 `/团 休整` 并度过安全时段后回满。

### 装备与栏位管理
```text
/团 背包             # 私聊或群聊查看个人物品与剩余次数
/团 装备 精工短剑    # 佩戴到对应装备栏
/团 卸下 精工短剑    # 卸下并放入背包
/团 丢弃 沉重石块 2  # 舍弃不需要的道具
```

## 5. 协作与集体表决

当遭遇全队共同面临的重大抉择或突发事件时，开启集体表决流程。

### 全队行动提议
任何玩家都可在非单人行动时刻发起全队行动倡议：
```text
/团 全队 所有人分散寻找避难所
```

### 投票表决
全队成员对正在进行的集体决策进行投票：
```text
/团 投 A
/团 表决             # 查看当前各选项的得票情况与截止时限
```
- 若出现平票，将触发重新表决或由主持人裁定。
- 投票截止后，系统汇总全队意志并驱动下一段团队剧情。

## 6. 私聊与群聊联动

为保持群聊整洁并保护玩家个人信息，321Roll Lite 深度支持群聊与私聊分离：

| 操作分类 | 建议执行途径 | 表现说明 |
|---|---|---|
| 建卡与选职 | 私聊 bot | 避免刷屏与占位，选职成功后群内发送简报 |
| 查看角色与背包 | 私聊 bot | 回执直接留在私聊，保护背包与底牌 |
| 使用辅助道具 | 私聊 bot | 消耗与状态留在私聊，必要影响同步全局 |
| 跑团行动与投骰 | 群聊 / 私聊均可 | 私聊中发出的 `/团 选` 或 `/团 行动` 会自动将结果转发至群聊 |
| 多桌切换 | 私聊 bot | 玩家同时参与多个群的团桌时，使用 `/团 切换 [序号]` 绑定当前私聊目标 |
