# 主持人控场与裁判手册

在 321Roll Lite 中，开团者即为主持人（或具有管理权限的管理员）。虽然 AI 承担了讲故事与选项生成的繁重工作，但团桌的节奏把控、戏剧张力、突发状况与公平裁定依然离不开主持人的掌舵。

---

## 1. 跑团生命周期管理

主持人负责把控整场跑团的启动、间歇与收场：

```text
/团 开演              # 队伍入座完毕后，开始故事，AI 吐出开场大幕与第一轮选项
/团 暂停              # 临时有事或深夜休息时，冻结团桌输入
/团 恢复              # 解除暂停状态，继续冒险
/团 前情              # 让 AI 写一段前情提要，帮隔了几天回来的队友接上剧情
/团 人数 4            # 限制本桌最大玩家席位数（例如设定为 4 人）
/团 完结 破晓终局     # 跳过常规步骤直接宣布本团圆满完结
/团 关闭              # 收桌清场，本桌记录归档至后台
```

### 存档与读档
跑长线战役时，可随时保存与读取进度：
```text
/团 存档 第三幕水下密室前   # 创建具名存档
/团 存档列表               # 查看本桌所有历史存档点
/团 读档 2                 # 回滚读取指定序号或名称的存档
```

隔了一段时间再续团时，插件会自动补一段“前情提要”：暂停超过半小时后 `/团 恢复`（读档后也要恢复才会继续），或者故事停了 12 小时以上、有人第一次行动时，都会先发提要再继续。提要只根据大家已经看到的剧情来写，不会泄露世界的秘密。想把整局故事留存下来，可以在后台团桌页点“导出整本故事”。

---

## 2. 节奏控制与席位调度

遇到玩家临时挂机、掉线或需要特定角色挺身而出时，主持人拥有最高调度权：

### 轮次与顺序干预
```text
/团 主持 轮到 林晓         # 强制将当前行动权直接移交给林晓（支持写名字、序号或 @对方）
/团 主持 跳过             # 强制跳过当前超时的玩家
/团 主持 顺序 陆巡 林晓 白歌 # 重新编排后续轮流行动的先后顺序
```

### 时限调节
```text
/团 主持 限时 10          # 将每回合行动限时调整为 10 分钟（1–1440）
/团 主持 限时 0           # 取消倒计时（无限时模式）
/团 主持 限时 默认        # 恢复跟随系统全局配置
/团 主持 表决时限 3       # 将集体投票的倒计时调整为 3 分钟
```

> 使用 QQ 官方机器人时，超时自动行动、表决结算和约团提醒都是插件主动发到群里的。请让群主或管理员在手机 QQ 的群机器人设置里打开“允许机器人主动在群聊内发言”，否则这些消息要等群里有人发下一条 `/团` 才会补发。

### 时光回退（悔棋与纠错）
若玩家操作失误、发生严重误解或模型逻辑崩溃，可撤回历史行动：
```text
/团 主持 回退
```
- 每次回退将完整撤回最近一步行动：**骰子、扣减资源、生成的正文以及玩法记录同步撤回**。
- 单桌最多可连续撤回最近 **5 步**。

## 3. 剧情走向与文风定制

AI 生成的故事风格可以由主持人随时校准，无需重启。

### 直接叙述与推进
```text
/团 主持 直述 突然，头顶的水晶吊灯轰然坠地，大厅陷入一片漆黑！  # 插入一段官方旁白
/团 主持 推进 远处传来了守卫的号角声                          # 强制推动故事向下一阶段发展
/团 主持 换幕 2                                             # 强制切换至第 2 幕
/团 主持 换幕 夜渡：钟声停下的那一刻，渡口亮起了灯              # 核心版：第一幕之后由主持人给新的一幕命名
/团 主持 新场景                                             # 确认切换场景（刷新每场景恢复的技能与物品）
```

### 暗中指引（幕后导演提词）
给 AI 叙事模型的私密导演提示，普通玩家不可见：
```text
/团 主持 指引 接下来让那个独眼商人表现得极其可疑，但实际上他是好人
/团 主持 指引 清除                                          # 清空自定义指引
```

### 叙事设置：即兴、对白与篇幅
开桌时，团桌会沿用世界的叙事默认；之后主持人可以逐项改成本桌设置，从下一段正文开始生效。写“默认”就回到开桌时的世界默认。
```text
/团 主持 即兴 稳健    # 发挥空间：严谨、稳健、均衡、灵动、奔放、默认
/团 主持 文风 多对白 悬疑阴森、对话充满言外之意  # 对白比例，后面可以补充文笔要求；写“默认”恢复并清除补充
/团 主持 篇幅 简洁    # 每段长短：不限、简洁（100–300 字）、均衡（300–600 字）、长篇（600–1000 字）、默认
```
- 对白比例可选：`多对白`、`偏对白`、`均衡`、`偏描写`、`多描写`。
- 只发指令名（例如 `/团 主持 即兴`）可以查看当前值，以及它来自世界默认还是本桌设置。
- 后台团桌页的“叙事设置”可以做同样的调整：打开某一项的“自定义”后点选想要的档位。
- 主持人指引和这三项互不影响，写指引不会覆盖即兴程度。

### 重试与手动选项
```text
/团 主持 重试              # 正文生成不满意或格式异常时，重新生成一次
/团 主持 选项 躲进木桶｜硬闯大门｜点燃草堆  # 自定义本轮供给玩家的候选选项
```

## 4. 裁定、暗中调整与突发事件

### 发起即时检定
遭遇陷阱、突袭或察觉暗号时，主持人可指定单名玩家立即投骰：
```text
/团 主持 检定 林晓 敏捷 困难 [受伤] 躲避头顶掉落的滚石
```
- 附带 `[受伤]` 标记时，若检定失败，受损代价将在下一回合正文后由系统自动结算生效。

### 幕后暗调（私聊神仙手）
调整玩家的生命、法力、道具数量或 NPC 态度。**建议在私聊中发给 bot**，不会在群聊剧透：
```text
/团 主持 调整 林晓 体力 -2
/团 主持 调整 警长 态度 +1
```
- 提交后会进入“待生效缓冲池”，**在下一回合正文生成完成后自然公布并生效**，避免机械感。生效前可在后台撤回。

### 触发集体事件
```text
/团 主持 集体事件          # 立即在群内抛出一个全队突发危机
/团 主持 结束表决          # 提前截断并结算当前全队投票
/团 主持 事件频率 6        # 设置每经过 6 轮自动触发一次集体事件（0 为关闭）
```

## 5. 审稿模式（导演把关制）

在关键大戏或严肃战役中，主持人可开启审稿模式，杜绝 AI“发癫”或不可逆的剧透：

1. 主持人先私聊 bot 任意发一条 `/团` 指令完成私信握手。
2. 在群内或私聊开启审稿：
   ```text
   /团 主持 审稿 开
   ```
3. 开启后，**每轮生成的正文不会直接发进群聊**，而是先私聊推送给主持人。
4. 主持人检视草稿：
   - 满意通过：私聊发送 `/团 主持 发布`，正文正式发到群里。
   - 需要修改：私聊发送 `/团 主持 重写 不要直接杀死守卫，改为将他击晕`，模型按意见重写后再次递交审阅。
5. 关闭审稿：`/团 主持 审稿 关`。

## 6. 席位秩序与交棒

维护群内文明跑团秩序与主持人交接：

```text
/团 主持 入座 关          # 满员或开演后锁定席位，禁止新玩家加入
/团 主持 移出 恶心玩家 [刷屏捣乱]  # 请离指定玩家
/团 主持 放行 该玩家昵称   # 允许此前被移出的玩家重新入座
/团 主持 退回 角色名 [背景不符]   # 收回角色卡，要求该玩家重新建卡
/团 主持 暂离 角色名      # 将挂机者标记为暂离，跳过其轮流行动
/团 主持 返回 角色名      # 恢复暂离者回席
```

### 禅让与交接主持
```text
/团 主持 交棒 林晓        # 向同桌玩家林晓发起交棒邀请
```
- 被邀请人发送 `/团 接棒` 即可成为新任主持人；发送 `/团 拒绝接棒` 维持现状。
- 管理员使用交棒指令则立即强制生效，无需对方接棒。

### 玩家人设

玩家可以把自己的人设卡（来自 SillyTavern 角色卡或手写）带进这一桌。人设只影响 AI 怎么写这个角色的性格、经历和说话方式，属性、技能和物品仍按职业。

```text
/团 主持 人设              # 查看本桌每个人带的人设和融入后的身份
/团 主持 人设 关           # 这一桌只按职业来，AI 不再参考人设，玩家也不能再带人设
/团 主持 人设 开           # 恢复
/团 主持 人设 清除 林晓    # 清除某个角色的人设
```

- 开关和清除都从下一段正文起生效；关闭后已带上的记录仍保留，重新打开即恢复。
- 故事开始后玩家不能自己更换人设，需要换时由主持人清除，再让玩家重新建卡。
