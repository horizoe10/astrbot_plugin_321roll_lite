# 调查推理与证词对质指南

在悬疑、解谜与侦探题材的故事中，单纯的物理对抗无法揭开迷局。321Roll Lite 提供了一套完整的线索记录、搜查检定、假设推演与证词对质系统，帮助调查员们建立扎实的证据链。

---

## 1. 编号系统与记录流转

所有在故事中发现的线索、证词、假设与结论，系统都会分配一个全局唯一的数字编号（例如 `#1`、`#2`）。

- **查看所有调查记录**：`/团 记录 线索` 或 `/团 记录 全部`
- **查看单条详情与后续提示**：`/团 查看 #编号`

每条记录回执末尾都会注明当前条目支持的后续操作，方便玩家直接串联下一步推断。

---

## 2. 搜查与线索收集

### 搜查检定
当来到犯罪现场、密室或疑点区域时，主动开展细致搜查：
```text
/团 搜查 讲台与暗门：翻找底层抽屉并敲击暗格 [观察 标准]
```
- 搜查成功后，AI 与叙事引擎将揭露隐藏的信息，并自动生成一条具有编号的线索。

### 手动记录线索
在对话或场景描述中发现可疑痕迹时，可将其归档为正式线索：
```text
/团 线索 亲见 染血的手帕：在钟楼二楼转角发现带有紫罗兰暗纹的手帕
/团 线索 听说 巡夜人的传言：门卫提到昨夜子时钟声多响了一声
```
- 标记为 `亲见`（亲眼所见）或 `听说`（传闻转述），有助于后续评估线索的可靠性。

### 引用世界设定
世界观中若包含公开的背景常识、宗族历史或地理记录，可直接将其引入当前调查：
```text
/团 引用 钟楼历史
```
- 设定将作为既成事实进入证据库，供全队随时对照与推断。

---

## 3. 假设构建与推理闭环

收集到线索后，玩家可以组织推论并尝试得出最终结论。

### 提出假设
结合当前掌握的情报，提出可能的事实真相：
```text
/团 假设 凶案发生时间：真凶在子时前就已经进入钟楼并在齿轮处动了手脚
```
系统将为该假设生成独立编号（如 `#5`）。

### 支撑与反驳
利用已归档的线索强化或推翻某项假说：
```text
/团 假设 #5 支持 #2    # 用编号 #2 的线索支持编号 #5 的假设
/团 假设 #5 反驳 #3    # 指出编号 #3 的线索与该假设互相矛盾
```

### 撤回假设
若发现假说从根本上不成立，提出人可主动撤回：
```text
/团 假设 #5 撤回
```

### 盖棺定论
当证据链充分、队伍达成共识后，正式采纳或否定假设：
```text
/团 结论 #5 采纳
/团 结论 #5 否定
```
采纳的结论将固化为不可动摇的调查成果，甚至影响主线剧情和结局分支走向。

---

## 4. 证词收集与质询对质

面对嫌疑人、目击者或神秘 NPC 时，调查员可通过证词系统进行问话与逻辑交锋。

### 记录口供证词
将 NPC 的关键发言留档存证：
```text
/团 证词 老管家：昨晚暴风雨时我一直在厨房备餐，从未离开过主屋一步
```
生成证词记录编号（如 `#7`）。

### 深入追问
针对证词中的模糊或疑点展开质询：
```text
/团 追问 #7 为何你的大衣下摆沾有花园里的湿泥？ [洞察 困难]
```
- 检定成功将迫使对方透露更多细节，或暴露神色慌张等破绽。

### 出示证据对抗
将某条物证线索直接摔在证人面前，击破其心理防线：
```text
/团 出示 #7 #2 这块染血手帕上的暗纹正是你家徽的标记！ [威吓 困难]
```
- 成功出示将直接瓦解伪证，往往能逼问出案件的关键转折。

### 对照多份证词
当两个人的证言存在不可调和的矛盾时，执行证词交叉比对：
```text
/团 对照 #7 #8 巡夜人声称在花园见过老管家，与老管家在厨房的证词冲突
```
- 对照记录将形成明确的矛盾点，为进一步审讯提供强力支撑。

## 5. 调查玩法速查表

| 指令格式 | 说明 | 是否需要检定 |
|---|---|---|
| `/团 搜查 目标：方式 [属性 难度]` | 搜寻场景证据与隐秘物品 | 是 |
| `/团 线索 [亲见|听说] 标题：内容` | 记录一条新线索 | 否 |
| `/团 假设 标题：推断` | 提出推论仮说 | 否 |
| `/团 假设 #假设 支持|反驳 #线索` | 用线索支撑或辩驳假说 | 否 |
| `/团 结论 #假设 采纳|否定` | 裁定并固化假说结论 | 否 |
| `/团 引用 <条目名>` | 调阅世界观公开条目 | 否 |
| `/团 证词 证人：证词` | 记录人物关键发言 | 否 |
| `/团 追问 #证词 问题 [属性 难度]` | 盘问证词深层细节 | 是 |
| `/团 出示 #证词 #线索 矛盾 [属性 难度]` | 物证与口供对质 | 是 |
| `/团 对照 #证词 #证词 说明` | 比对两份冲突证言 | 否 |
