# 社交交涉与对抗冲突指南

跑团既有唇枪舌剑的利益博弈，也有命悬一线的白刃战与惊心动魄的追逐。321Roll Lite 将复杂的战斗与社交网简化为清晰的轨道、交锋与态度进阶机制。

---

## 1. 人物与态度系统

剧情中出场的所有关键 NPC 均会被后台自动记录并追踪。

### 态度七档机制
NPC 对队伍的初始态度通常为**中立**。根据玩家的言行与检定成败，态度将在以下七档之间上下浮动：

```text
敌对 ◄— 戒备 ◄— 冷淡 ◄— 中立 —► 友善 —► 信任 —► 盟友
```

- **查看所有人物与态度**：`/团 人物` 或 `/团 人物 [NPC名]`。
- **争取关系或改善态度**：
  ```text
  /团 关系 人物 警长：为他递上一杯热咖啡并承诺破案 [魅力 标准]
  /团 关系 势力 雇佣兵团：出示商会保函争取中立立场 [交涉 困难]
  ```
  检定成功将提升其一级态度，失败则可能引发警惕或下降。

### 同伴羁绊与目标
记录和推进同伴的个人追求：
```text
/团 目标 林晓：寻回失踪的学者导师的调查笔记
/团 目标 #4 实现
/团 目标 #4 放弃
```

## 2. 交涉与谈判

面对商人、领主或谈判对手时，开启正式的交涉协商流程。

### 开启交涉
设立谈判对象与核心议题：
```text
/团 交涉 港口总督：通行关税减半与停靠许可
```
生成交涉编号（如 `#3`）。

### 陈述论据与争取筹码
在交涉中阐述自身理由并进行检定：
```text
/团 交涉 #3 强调我们的商队能为港口带来急需的北方药材 [说服 标准]
```

### 拟定条款与签署协议
随着谈判推进，双方可以将共识固化为正式条款：
```text
/团 条款 #3 队伍承诺协助清剿近海海盗，总督免除本月全部泊位费
```
当双方认可后，由当事人完成签署履约：
```text
/团 签署 #3 1    # 签署编号 #3 交涉中的第 1 条条款
```

## 3. 独立冲突与交锋（战斗）

321Roll Lite 摒弃了繁琐的网格战棋走格子，采用动态**进度轨道**（默认 3–6 格）来判定势态消长。

### 发起冲突
明确对手与本次冲突的赌注（胜负代价）：
```text
/团 冲突 废墟守卫：突破大门进入内殿 [4]
```
*方括号中的数字为胜负进度轨道长度（3–6，默认 4 格）。*

### 参战与加入
同桌的其他队友可随时加入该场对抗，共同积累胜势：
```text
/团 冲突 #6 加入
```

### 进行交锋行动
轮到自己时，发起一次具体交锋行动并完成检定：
```text
/团 交锋 #6 侧翼包抄用盾牌猛击其关节 [力量 标准]
```
- 检定成功推进胜势轨道；检定失败可能导致对手占优或承受负面影响。

### 战术姿态（孤注一掷）
在紧急关头，玩家可选择高风险的极端姿态搏取更大收益：
```text
/团 交锋 #6 孤注 舍弃防御全力掷出符文长矛 [体质 困难]
```
- **孤注姿态**：大幅提升成功时的推动幅度，但若检定失败将承受更严重的负面代价。

### 让步与停火
当局势不可挽回时，主动认输止损，保留退路：
```text
/团 冲突 #6 让步
```
- 让步后由 AI 给出妥协收场（例如被俘、负伤逃离），避免队伍无谓阵亡。

## 4. 追逐战

追逐战是冲突玩法的一种特殊形态，通过距离刻度模拟猎手与逃亡者的紧张竞逐。

### 开启追逐
明确追逃目标与初始距离（2–4 格，默认 3）：
```text
/团 冲突 追逐 追赶 窃贼头目 [3]
/团 冲突 追逐 逃离 机械巡卫 [4]
```

### 追逐交锋
在追逐中利用地形、障碍或速度优势改变距离：
```text
/团 交锋 #7 翻越屋顶瓦砾抄近道逼近 [敏捷 标准]
/团 交锋 #7 推倒货架阻碍追兵步伐 [力量 简单]
```
- 追赶方将距离缩减至 0 即告截获成功；逃亡方将距离拉大超出上限则成功脱身。

## 5. 辩论对抗

当面对法庭辩护、学者舌战或议会辩难时，开启回合制辩论。

### 发起辩论
设立辩题、己方核心立场与论战轮数（3–6 轮）：
```text
/团 辩论 领地归属权：基于古老誓约领地应归原住民所有 [3]
```

### 辩论交锋
每轮提出论据、质问对方漏洞并检定：
```text
/团 交锋 #8 引用百年前的拓荒宪章驳斥对方的正统性 [学识 困难]
```
在设定的回合数耗尽前，积累足够胜势以赢得全场听众与裁判的认可。

## 6. 交互对抗指令速查

| 指令格式 | 说明 |
|---|---|
| `/团 人物 [名字]` | 查看所有登场 NPC 及其当前态度档位 |
| `/团 关系 人物|势力 对象：方式 [属性 难度]` | 争取关系好感或记录互动往来 |
| `/团 目标 同伴：目标` | 确立同伴心愿目标 |
| `/团 交涉 对象：议题` | 开启一场正式利益谈判 |
| `/团 交涉 #交涉 理由 [属性 难度]` | 提出谈判说辞并投掷检定 |
| `/团 条款 #交涉 内容` | 提出拟定协议条款 |
| `/团 签署 #交涉 条款序号` | 本人正式签署条款 |
| `/团 冲突 对手：赌注 [轨道格数]` | 开启一场独立对抗/战斗 |
| `/团 冲突 追逐 追赶|逃离 对象 [距离]` | 开启一场距离竞逐追逐战 |
| `/团 冲突 #冲突 加入` | 协助队友加入对抗 |
| `/团 交锋 #对抗 [孤注] 行动 [属性 难度]` | 执行一次对抗交锋行动 |
| `/团 冲突 #冲突 让步` | 主动妥协止损撤出战斗 |
| `/团 辩论 辩题：立场 [轮数]` | 展开一场议题公开辩论 |
