## 群里就能跑的团

想跑团，却凑不齐时间、找不到主持人、新人看不懂规则书？装上 321Roll Lite，群里任何人都能在几分钟内开一桌：AI 主持人照着世界设定讲故事，插件替大家掷骰子，玩家轮到自己时点一个选项，或者直接写一句想怎么做。不用下载新应用，不用另开房间，聊天和跑团在同一个群里进行。

- **AI 当主持，故事跟着你们走。** 每一轮都根据大家的选择即兴续写，NPC 会记住队伍做过的事，态度从敌对到盟友分七档变化。
- **骰子由插件掷，AI 改不了。** 带检定的行动先由插件掷 d20、算出成败，结果落定后再交给 AI 写正文，运气和实力都算数。
- **新人点选项也能玩。** 每轮给出 A–D 四个选项，并标好难度和风险；老手可以自由描述行动，带上技能和道具搏一把加值。有人掉线也不会卡住全桌，超时会自动选风险最低的一项。
- **不止打打杀杀。** 搜查线索、推理结论、对质证人、谈判签约、追逐对抗、制定计划、抽机运、问神谕、走向多结局，共 16 类文字玩法。
- **开箱就有六个世界。** 放学后多敲一下的钟楼、群兽迁徙之年的狩猎、矿脉之下的祖约、用剑刻下潮痕的剑冢、当掉整座城昨天的霓虹典当行、锁园里自己响起的锣，选一个就能开演。
- **私事私聊办。** 建卡、看角色卡、翻背包、用道具都可以私聊 bot 完成，群里只留下故事。

它适合想在群里带团又没空当主持的群主、想试试跑团却没碰过规则书的新人，也适合想写自己世界观的创作者：后台有可视化的世界编辑器，写好的世界可以导出分享。

## 三分钟开第一桌

1. 在 AstrBot 插件市场安装，或上传插件 zip；确认 AstrBot 已经配好聊天模型。
2. 管理员在群里发 `/团 开启`，按序号选一个世界。
3. 朋友们发 `/团 加入` 入座，再私聊 bot 发 `/团 选职业 1 角色名` 建卡。
4. 主持人发 `/团 开演`，AI 写出开场和第一轮选项，故事开始。

之后轮到谁，谁就发 `/团 选 A`。忘了指令就发 `/团 帮助`。

## 关于本插件

321Roll Lite 是 321Roll 的 AstrBot 群聊文字版。它沿用 321Roll 的世界引擎和世界包格式，可以在 QQ、Telegram 等 AstrBot 支持的群聊里使用。管理员在 AstrBot 后台的插件页面里管理团桌、世界包和玩法开关。

- 版本：0.1.0
- 世界引擎：party321-story-engine 1.0.0rc26（随插件附带，见 `vendor/`）
- 世界格式：`321roll.world-template/1`，附带六个预设世界包（只含文字）
- AstrBot：>= 4.26，Python >= 3.11（AstrBot 4.27 自带 3.12）
- 运行时没有第三方依赖

## 安装

1. 在 AstrBot 插件管理中填入仓库地址 `https://github.com/horizoe10/astrbot_plugin_321roll_lite` 安装；也可以上传 `dist/astrbot_plugin_321roll_lite-v0.1.0.zip`（用 `python tools/build_zip.py` 生成），或把本仓库目录放进 AstrBot 的 `data/plugins/`。
2. 在插件配置中填写管理员用户 ID；AstrBot 管理员默认也有权限。需要时开启群白名单。
3. 确认 AstrBot 已配置聊天模型。默认使用每个群当前的聊天模型，也可以在插件配置里指定模型提供方 ID。

## 开一局

```text
/团 世界                     查看可开的世界
/团 开启 5                   管理员开团（这里选第 5 个世界）
/团 加入                     玩家在群里入座
/团 职业                     私聊 bot 查看职业（群里发也可以）
/团 选职业 1 林晓             私聊 bot 选职业并给角色取名，群里会收到一句公告
/团 开演                     主持人开始，AI 生成开场和第一轮选项
/团 选 A 小心地推门           轮到你时选一个选项（可补一句演绎）
/团 行动 我去检查闪烁的灯      或者自由描述行动
/团 选 A [用 手电筒]          检定时带上技能或物品，加值计入骰子
```

带检定的行动由平台掷 d20 加属性修正，对抗难度（简单 8、标准 12、困难 15、极难 18）；骰果先记下来，再交给 AI 写正文。回合超时（默认 5 分钟）会自动选择风险最低的选项；每桌可以单独调整选项时长：主持人发送 `/团 主持 限时 10`（分钟，1–1440）、`/团 主持 限时 0`（不限时）或 `/团 主持 限时 默认`（跟随全局），管理员也可以在后台团桌页的“回合限时”里改，当前回合立即按新时长重新计时。发送 `/团 帮助 <分类>` 查看每类指令的写法。

## 指令速查

| 分类 | 指令 |
|---|---|
| 开团 | 世界、开启、加入、职业、选职业、角色、阵容、退出、暂离、返回 |
| 行动 | 选、行动、跳过、回合、顺序、回顾、全队、投、表决 |
| 道具 | 背包（技能）、使用、装备、卸下、丢弃 |
| 调查 | 线索、搜查、假设、结论、引用、证词、追问、出示、对照 |
| 交涉 | 交涉、条款、签署、关系、目标、人物 |
| 对抗 | 冲突（含追逐）、辩论、交锋 |
| 计划 | 计划、执行、时间、期限、项目、休整 |
| 叙事 | 机运、神谕、转变、结局、尾声 |
| 记录 | 记录（列出 `#编号`）、查看 `#编号` |
| 主持 | 开演、暂停、恢复、完结、关闭、人数、存档、存档列表、读档；主持 直述、指引、推进、跳过、选项、重试、换幕、新场景、集体事件、结束表决、事件频率、限时、表决时限、轮到、顺序、回退、检定、调整、篇幅、文风、审稿、发布、重写、交棒、移出、放行、暂离、返回、入座、退回；接棒、拒绝接棒 |
| 私聊 | 切换（选择私聊操作哪一桌） |

玩法记录统一用 `#编号` 引用，例如 `/团 假设 #3 支持 #2`。需要检定的玩法在句末写 `[属性 难度]`，例如 `/团 搜查 讲台：翻找抽屉 [观察 标准]`。占用行动的玩法（检定、抽签、耗时、休整）只能在轮到自己时使用，用完回合交给下一位。

每个玩法的回执都会写出“接下来可以”做什么，`/团 查看 #编号` 也会给出这条记录的下一步。

### 技能与物品

规则与 321Roll 全量版一致。检定时在行动句末写 `[用 名称]`（可写多个，用顿号隔开）：条目绑定的属性必须与本次检定一致，加值计入 d20；所有消耗先按行动前的资源核对，本次的回复不能抵本次的消耗。`/团 使用 名称` 不掷骰，直接结算消耗与回复、扣一次次数，物品按“每次用掉”的数量减少；不占回合，但要等正在结算的行动结束。次数按条目设定恢复：“每幕恢复”在换幕或 `/团 主持 新场景` 时恢复，“休整后恢复”在休整后恢复。带装备栏位的物品可以装备、卸下，物品可以丢弃。

### 私聊

玩家在群里入座后，可以私聊 bot 建卡、查看角色卡与背包、使用物品、查看人物和记录。私聊里发出的行动、投票和玩法，结果会发到群里，私聊收到“已发到群里”和结果的前几行（含记录编号）；只是查看的指令（如 `/团 关系`、`/团 结局`、`/团 时间`）结果留在私聊。同时坐在几个群的团桌上时，用 `/团 切换` 选择私聊操作哪一桌。

### 人物与态度

剧情里出现的 NPC 会自动记下，默认中立。态度针对整个队伍，分敌对、戒备、冷淡、中立、友善、信任、盟友七档；`/团 关系 人物 名字：做法 [属性 难度]` 成功升一档、失败降一档，`/团 人物` 列出所有人物、当前态度和每位玩家带来的升降。

### 主持人工具

开团的人就是主持人，主持人和管理员可以使用下面这些指令。指名玩家时写角色名、昵称、`/团 阵容` 里的座位序号，或者直接 @ 对方。

- **节奏**：`/团 主持 轮到 角色` 把当前回合交给指定的人，`/团 主持 顺序 角色一 角色二` 调整行动顺序，`/团 主持 回退` 撤回最近一步行动（骰子、资源、正文和玩法记录一起撤回，最多 5 步），`/团 主持 表决时限 5` 把表决改成 5 分钟。
- **裁定**：`/团 主持 检定 林晓 观察 困难 [受伤] [理由]` 让一位玩家立即检定，结果写进剧情；带“受伤”时，失败的代价在下一回合正文后生效。`/团 主持 调整 林晓 体力 -2` 调整资源、物品、技能、次数或人物态度，同样在下一回合正文写完后生效；这条指令可以在私聊里发，不会剧透。
- **正文**：`/团 主持 篇幅 简洁|均衡|长篇` 控制每段正文的字数，`/团 主持 文风 多对白 冷峻克制` 设定对白与描写的比例和风格。`/团 主持 审稿 开` 之后，每段正文先私发给主持人，主持人在私聊里发 `/团 主持 发布` 公开，或 `/团 主持 重写 意见` 按意见重新生成。开启前主持人需要先私聊 bot 发一次任意 `/团` 指令。
- **席位**：`/团 主持 交棒 角色` 邀请同桌接任主持，对方发 `/团 接棒` 生效（管理员交棒立即生效）；`/团 主持 移出 角色 [原因]` 请人离桌，之后要 `/团 主持 放行 昵称` 才能再入座；`/团 主持 暂离`、`/团 主持 返回` 替挂机的人切换状态；`/团 主持 入座 关` 暂停新玩家加入；`/团 主持 退回 角色 [原因]` 收回角色，请玩家重新建卡。

### 模型兼容

DeepSeek 等通过 AstrBot 调用、没有严格结构化输出的模型，常会漏写值为 null 的字段，或照抄输入里的多余字段。插件会先把这类格式问题修好，再交给故事引擎校验，正文和选项不会被改写。修不好的输出会按具体字段（例如“progress 缺少字段 goal”）写进下一次重试的提示，并记录在后台“运行”页。

完整的玩法取舍和指令设计见 [docs/PLAY_SCOPE.md](docs/PLAY_SCOPE.md)。

## 管理后台

在 AstrBot 后台的插件页面打开“321Roll Lite”，顶部导航七页：总览、团桌、世界、玩法、消息、运行、设置。界面沿用 321Roll R39 的白金/黑金视觉，跟随 AstrBot 的深浅色主题；世界封面用配色加大字，团桌页用幕进度条、倒计时环、席位点和资源条显示跑团进度。

团桌详情里的主持操作等同于主持人在群里发送对应的 `/团` 指令，回执会推送到群里；所有后台写操作都会写入操作记录。
每张席位卡上有“轮到他、设为暂离、退回重建、交棒给他、请离”等按钮；审稿模式下，待审阅的草稿会显示在“此刻”里，可以直接发布或按意见重写。

团桌详情还可以“主持调整”：修改角色的资源、物品数量、技能、剩余次数，或某个人物对队伍的态度。调整提交后先进入待生效列表，等模型写完下一回合的正文后才生效，并在群里公布；生效前可以撤销。

## 自定义世界

预设世界不能直接修改。打开任一预设世界，点“复制为自定义世界”，就会进入编辑器：左侧七个步骤（基本信息、规则、技能与物品、职业、设定条目、幕与结局、检查与保存）会实时标出每一步还有几个问题，右侧配有封面、难度刻度、人数、职业属性对比等即时预览。改好后可以保存到后台，也可以“导出 JSON”得到一个 `.world.json` 文件，日后在“导入世界文件”里原样导回。想分享给其他 Lite 管理员，用世界详情页的“导出安装包”得到 zip，对方在世界市场里上传即可。未保存的修改会自动留在浏览器草稿里，刷新后可以恢复。

## 消息样式

“消息”页有一个全局推送格式开关（Markdown / 纯文本）。只有支持 Markdown 的平台（QQ 官方机器人、Telegram、飞书、KOOK、Discord、Mattermost）会收到 Markdown，OneBot（aiocqhttp）等平台总是收到纯文本。QQ 官方机器人需要开通原生 Markdown 权限；被拒收一次后，插件会自动改发纯文本并记住该平台，可在“消息”页重新尝试。

一轮行动依次发送个人状态、故事正文、行动选项三段，间隔 0–3 秒可调，也可以合并成一条。三段各有一个“转为图片”开关，打开后按插件自带的卡片版式出图，可选白金或黑金配色：个人状态卡展示头像徽章、骰子和检定算式、资源条；故事正文卡首字放大成金色，开场、换幕和换场景时顶部放世界横幅（市场安装的场景图，没有图就用配色加大字的封面）；行动选项卡把每个方向的检定和失败代价列清楚，指令单独成一行。卡片经 AstrBot 的渲染服务出图，失败时先改用 AstrBot 默认文转图，再失败就发文字。页面右侧的预览与群里实际收到的内容使用同一套排版。

## 世界包

插件自带六个预设世界的文本版（第七个不思议、狩火、灰冠之下：祖约、无名剑冢、霓虹典当行、封箱戏），放在 `worlds/` 下，不带图片，所以插件本身很小。后台可以启用、停用，也可以导入自己写的 `321roll.world-template/1` 世界。开团时会冻结一份世界快照，之后修改、更新或卸载世界都不影响进行中的团桌。

带场景图的版本在“世界 → 世界市场”里安装。市场读取 GitHub 上的索引文件，默认是本仓库 `worlds` 分支的 `index.json`，每个世界一个 zip 安装包，里面是世界数据和 1280 宽的场景图（封面、各幕、地点、结局）。安装预设世界的图文版后，它会替换插件自带的文本版，卸载后恢复文本版；索引里出现更高版本时，市场会提示更新。

- **下载线路**：GitHub 地址默认改走 jsDelivr 镜像，失败再直连；也可以选直连，或填一个代理前缀。
- **离线安装**：在市场页上传 zip，或填写 zip 的网址（可附 sha256 核对）。
- **安全**：安装包只能包含 `manifest.json`、`world.json` 和 webp/png/jpg 图片，大小上限 32 MB。安装前会逐个核对文件大小和 sha256，检查图片格式，再交给世界引擎编译，全部通过才会写入。安装包里的内容不会被执行。
- **发布自己的世界**：把导出的安装包和一份 `321roll-lite.world-index/1` 格式的 `index.json` 放进任意公开仓库，在市场页的“索引地址”里填上 raw 地址即可。`tools/pack_worlds.py` 生成官方索引的方式可以作为参考。

## 数据

所有数据存在 AstrBot 插件数据目录下的 `lite.sqlite3`；从市场安装的世界，原始安装包和场景图放在同一目录的 `market/` 下。角色只属于一个团桌，团桌收桌后记录保留在后台。Lite 不包含经验、等级、成就、货币等运营功能。
