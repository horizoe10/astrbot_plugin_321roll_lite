## 群里就能跑的团

**321Roll Lite** 是 321Roll 跑团平台的 AstrBot 群聊文字轻量版，由 **AI 酒馆**（`astrbot_plugin_tavern`）项目深度迭代演进而来。它沿用 321Roll 的世界引擎与世界包规格，可以在 QQ、Telegram 等 AstrBot 支持的群聊中直接使用。

想跑团，却凑不齐时间、找不到主持人、新人看不懂厚重的规则书？装上 321Roll Lite，群里任何人在几分钟内都能开上一桌：AI 主持人依据世界设定即兴讲述，插件自动掷骰裁定成败，玩家轮到自己时点选行动或自由演绎。无需额外下载客户端或切换房间，聊天与跑团融于同一个群聊之中。

- **AI 即兴主持，故事随心演变**：每一轮剧情均由大语言模型根据玩家决策实时续写。NPC 拥有长期记忆与态度机制，对全队的态度在敌对至盟友七档之间动态流转。
- **真实物理掷骰，判定客观可信**：带检定的行动先由插件后台投掷 d20 骰子并计算加值。骰果落定后再交给 AI 生成后续正文，兼顾角色属性实力与临场运气。
- **新人一键点选，老手自由演绎**：每轮提供 A–D 四个方向的选项建议，明晰标出难度与风险；老手可直接自由描述行动并挂载技能与物品。回合设有超时保护，挂机时自动托管，全桌永不卡顿。
- **丰富玩法矩阵，超越单纯战斗**：涵盖搜查线索、假设推理、证词对质、利益谈判、追逐对抗、拟定计划、机运问卜、神谕建议直至多结局走向，共计 16 类文字跑团玩法。
- **开箱即玩，六大世界任选**：插件自带深坑矿脉下的古老祖约，装好就能开演；放学后多敲一次的怪谈钟楼、迁徙猎杀之年的荒野狩猎、海潮剑冢、典当记忆的霓虹当铺与锁园自鸣的梨园戏班，可在后台世界市场一键安装。
- **私聊群聊双轨协同**：入座建卡、调阅属性、整理背包、暗中用药等私密操作均可在私聊完成，群聊专心呈现波澜壮阔的故事正文。

无论是想在群里带团又分身乏术的群主、对跑团充满好奇的新人，还是渴望创造独立世界观的作者，都能通过内置的可视化编辑器自由定制并分享专属世界。

## 三分钟开第一桌

1. **安装插件**：在 AstrBot 插件市场一键安装，或手动导入插件 zip；确保 AstrBot 已配置聊天模型。
2. **开启房间**：管理员在群聊中发送 `/团 开启`，按序号选择心仪的世界背景。
3. **入座建卡**：玩家发送 `/团 加入` 入座，私聊 bot 发送 `/团 选职业 1 角色名` 完成建卡。
4. **开演冒险**：主持人发送 `/团 开演`，AI 给出开场大幕与首轮选项，冒险正式启程。

后续轮到谁的回合，谁就在群里发送 `/团 选 A`。随时发送 `/团 帮助` 可调阅指令引导。

## 典型开局示例

```text
/团 世界                     查看当前可开的世界列表
/团 开启 5                   管理员开团（选择第 5 个世界）
/团 加入                     玩家在群里入座
/团 职业                     私聊 bot 查看本世界的可选职业（群内亦可）
/团 选职业 1 林晓             私聊 bot 选定职业并命名角色，群内同步入座公告
/团 开演                     主持人开启大幕，AI 铺陈现场情境并生成第一轮候选选项
/团 选 A 小心地推门           轮到当前玩家时选定选项（可追加一段演绎修饰）
/团 行动 我爬上房梁检查电线    也可以自主描述行动并声明检定属性
/团 选 A [用 手电筒]          挂载装备或技能，加值自动计入 d20 检定算式
```

涉及检定的行动由插件自动掷 d20 加上角色属性与装备修正，对抗预设难度（简单 8、标准 12、困难 15、极难 18）。骰果生成后交由叙事模型编写情节。回合默认设有 5 分钟倒计时（超时自动选择风险最低项），主持人可按需调增限时或设为无限时。

## 管理后台与世界编辑器

在 AstrBot 管理面板打开“321Roll Lite”插件页面，提供总览、团桌、世界、玩法、消息、运行、设置七大专区。界面继承 321Roll 白金与黑金双主题，完美贴合系统深浅模式：

- **实时团桌监控台**：以幕进度条、行动倒计时环、席位头像点阵与血量资源条全景呈现跑团实况。
- **远程主持指令中心**：后台提供等同于群聊指令的主持操作，点击即可跳过挂机玩家、退回建卡、交棒或请离；审稿模式下待审草稿实时显现，可一键发布或批注重写。
- **延时暗中调配**：支持在后台调整玩家属性、背包物品、剩余次数或 NPC 好感度。修改暂存入缓冲池，将在下一轮 AI 生成完正文后自然生效公布，保障游戏沉浸感。
- **可视化世界编辑器**：复制任意预设世界即可进入七步向导（基础信息、规则体系、技能物品、职业设定、世界条目、幕篇结局、校验导出）。右侧配备封面排版、难度刻度与职业属性对比表即时预览，支持导出 `.world.json` 或可发布的 zip 世界包。

## 世界包与世界市场

插件只随附一个纯文本预设世界 **灰冠之下：祖约**：深邃矿脉之下不可逾越的契约与古老回响（位于 `worlds/` 目录）。装好就能开团，插件本身也保持小巧。其余五个预设世界通过后台“世界 → 世界市场”从官方渠道安装：
1. **第七个不思议**：放学后多敲一下的钟楼，暗影潜行的校园悬疑怪谈。
2. **狩火**：群兽迁徙与灾厄之年的残酷原野猎杀。
3. **无名剑冢**：以剑刃在绝壁刻下浩瀚潮痕的武侠悲歌。
4. **霓虹典当行**：抵押整座城市昨日记忆的赛博朋克夜宴。
5. **封箱戏**：深宅锁园中不拨自鸣的铜锣，光怪陆离的梨园灵异。

世界市场默认绑定官方渠道，六个预设世界都提供包含高清场景图（1280 宽分辨率）的图文版，也可以填写其他索引地址安装社区世界。安装包支持校验 sha256 签名；安装灰冠之下的图文版会覆盖自带的文本版，卸载后自动恢复。

## 跨平台消息排版与卡片渲染

插件支持 Markdown 与纯文本自适应推送：
- 针对 QQ 官方机器人、Telegram、Discord、飞书、KOOK、Mattermost 等平台，优先推送原生排版。
- 针对不支持复杂样式的平台，自动优雅降级为纯文本排版。

支持开启**三段式图文卡片渲染**（白金 / 黑金双色调可选）：
- **个人状态卡**：绘制角色徽章、投骰算式与动态资源条。
- **故事正文卡**：首字大号烫金排版，幕次更迭与转场时自动载入宽屏场景大图。
- **行动选项卡**：整齐罗列 A–D 分支行动的难度、潜在代价与快捷指令。

## 安装与配置

### 运行环境
- AstrBot >= 4.26
- Python >= 3.11（AstrBot 4.27+ 自带 Python 3.12）
- 运行时无多余外部第三方包依赖（故事引擎已内嵌于 `vendor/`）

### 安装步骤
1. **市场安装**：在 AstrBot 插件市场搜索并安装；或在插件面板填入仓库地址 `https://github.com/horizoe10/astrbot_plugin_321roll_lite`。
2. **离线部署**：下载 Release 发布的插件 zip，在面板中上传安装，或直接解压至 AstrBot 的 `data/plugins/` 目录。
3. **配置管理员**：在插件配置中填入管理员用户 ID（AstrBot 系统超级管理员默认享有权限），按需启用群白名单。
4. **绑定模型**：确保 AstrBot 已配置对话模型。系统默认继承各群主模型，亦可在插件后台指定专属的模型提供方。

### 模型兼容性调优
针对 DeepSeek 等通过非严格结构化格式输出的模型，插件内置自动容错与格式修复管线，自动修补值为 `null` 的缺失字段或冗余内容，确保叙事逻辑顺畅递交。
